# Personal AI

A local-first personal AI platform built in Python.

The long-term objective is to build a modular AI system with
specialized domain agents for:

- Career
- Engineering / UAV / Embedded Systems
- Personal Finance
- Health & Fitness
- Future domains

## Principles

- Local-first
- Model-independent
- Personal data remains separate from source code
- Structured data is the source of truth
- LLMs provide reasoning and natural-language interaction
- Important answers should have provenance
- Sensitive domains require explicit access boundaries
- Autonomous actions require human approval
- AI workflows should be testable and reproducible

## Initial Technology Direction

- Python
- LangChain
- LangGraph
- Local LLM runtime
- Retrieval-Augmented Generation (RAG)
- SQLite / structured data
- Vector search
- pytest
